# Dr. Juan C. Cuevas-Tello – personal website

Static version of https://cuevastello.wixsite.com/homepage, ready for GitHub Pages.

## Files
- `index.html` – Home
- `about-me.html` – About Me
- `publications.html` – Publications
- `contact-me.html` – Contact Me
- `css/style.css` – shared styles
- `images/` – put the images here (see below)

## Publishing
1. Upload all files to the root of your repository (keep the `css/` and `images/` folders).
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Add your custom domain in the same Pages settings.
